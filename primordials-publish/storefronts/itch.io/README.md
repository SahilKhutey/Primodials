# 🌿 A LIVING ECOSYSTEM ON YOUR DESKTOP

**Polygonal Primordials** is a real-time artificial life simulation inspired by the classic Lotka-Volterra predator-prey equations. Watch populations rise and fall in beautiful polygonal harmony.

### — KEY FEATURES —
🧬 **Real ecological dynamics** — every organism births, hunts, flees, reproduces, and dies by the rules.  
🌿 **6 Distinct Biomes** — Algae Bloom, Deep Sea, Primordial Soup, Tundra, Coral Reef, Volcanic Vent.  
⚡ **High-performance engine** — 250,000+ entities at 60 FPS locked.  
🎨 **Polygonal art style** — distinctive bioluminescent vector aesthetic.  
💾 **100% Offline-First** — optional cloud sync for custom biomes.  
🛠️ **Open source** — MIT licensed, fork it, mod it, learn from it on GitHub.  

### — INSTALL & RUN —
* **Browser:** Play immediately in HTML5 Canvas 2D mode above.

# Primordials Landing Page

The marketing and documentation site for [Primordials](https://github.com/SahilKhutey/Primodials) — a living ecosystem on your desktop.

## 🛠️ Tech Stack
- **Next.js 14** (App Router, RSC)
- **TypeScript** strict mode
- **Tailwind CSS** + custom design tokens
- **Framer Motion** for animations
- **Lucide Icons**
- **Plausible Analytics** (privacy-friendly, zero cookies)
- **Vercel** ready

## 🚀 Development Quickstart

```bash
# Navigate to landing page directory
cd primordials-publish/primordials.dev

# Install dependencies
npm install

# Copy environment variables
cp .env.local.example .env.local

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## 📦 Production Build

```bash
npm run build
npm run start
```

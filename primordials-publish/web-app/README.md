# 🧬 Primordials — Web App

The desktop wallpaper and simulation application for Primordials.

## 🛠️ Stack
- **React 18** + **TypeScript**
- **Vite 5** for bundling
- **Tailwind CSS** for styling
- **Zustand** for state management
- **Canvas 2D** for 60 FPS spatial rendering

## 🚀 Development
```bash
npm install
npm run dev # Open http://localhost:5173
```

## 🏗️ Build
```bash
npm run build # Output in dist/
```

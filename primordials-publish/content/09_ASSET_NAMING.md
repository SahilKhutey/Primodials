# 📂 PRIMODIALS — Media Asset Naming Standard

All produced screenshots, videos, GIFs, and graphics follow this standard naming convention:

```
{category}--{subject}--{spec}--{variant}.{ext}
```

---

## 📸 EXAMPLES

### Screenshots
* `screenshot--algae-bloom--1920x1080--hero-A1.png`
* `screenshot--deep-sea--1080x1080--square-D2.png`
* `screenshot--volcanic-vent--1080x1920--vertical-V3.png`
* `screenshot--ui--1920x1080--dashboard-UI1.png`

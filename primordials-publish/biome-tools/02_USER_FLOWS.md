# 🎯 PRIMODIALS — Biome Authoring User Experience Flows

---

## 🌊 PRIMARY USER FLOWS

### Flow 1: Visual Authoring from Scratch (Beginner / Designer)
1. **Creation Trigger:** User clicks *"New Biome"* from the landing page.
2. **Template Population:** Editor loads a minimal single-producer ecosystem starter.
3. **Naming & Identity:** User titles the biome and assigns ambient palette colors.
4. **Trophic Population:** User adds 1 Grazer and 1 Predator via the preset wizard.
5. **Interactive Tuning:** User tweaks reproduction rate sliders while watching the live canvas until boom-bust oscillations reach equilibrium.
6. **Export & Sharing:** User clicks *"Export JSON"* or *"Submit to Community Gallery"*.

---

### Flow 2: Forking & Remastering Community Ecosystems
1. **Gallery Exploration:** User navigates through the Community Gallery.
2. **One-Click Fork:** User clicks *"Fork Biome"* on a published community submission.
3. **Instant Loading:** The editor mounts with complete species configurations and visual themes pre-populated.
4. **Modification:** User introduces a novel 4th trophic level (e.g. apex predator) and re-balances parameters.
5. **PR Submission:** Direct GitHub PR generation creates a PR with markdown summary and schema file attached.

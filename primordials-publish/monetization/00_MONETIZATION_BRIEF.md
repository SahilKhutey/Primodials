# 💰 PRIMODIALS — Monetization Brief

**Mission:** Build sustainable indie income from Primordials without compromising the open-source ethos, free user base, or community trust.

**Philosophy:** Make the free version genuinely great. Charge for convenience, identity, and extras — never for features people need.

**Year 1 Revenue Target:** $25,000  
**Year 2 Revenue Target:** $100,000  
**Year 3 Revenue Target:** $250,000  

---

## 🎯 CORE PRINCIPLES

### 1. Free First, Always
- Core desktop wallpaper: **forever free**
- All 6 default biomes: **forever free**
- Cloud save (basic): **forever free**
- Open source under MIT: **forever**

### 2. Pay for Convenience, Not Features
Premium tiers are about:
- 🎨 More biomes (curated, not gated)
- 🚀 Convenience (auto-updates, priority support)
- 🎖️ Identity (special roles, credits)
- 💼 Supporting the project (patronage)

### 3. Transparent Pricing
- No dark patterns
- No surprise charges
- Clear what each tier gets
- Easy to upgrade, easy to cancel

### 4. Indie-Friendly Pricing
- Prices that indie devs can pay
- Student/discount options
- Regional pricing where possible
- Lifetime option (no subscription trap)

### 5. Open Source Forever
- Source code stays MIT
- Free version stays fully featured
- Premium is additive, not restrictive

## 💸 REVENUE STREAMS (5)

### 1. Direct Sales (~40% of revenue)
- **itch.io:** Pay-what-you-want ($200-500/mo)
- **Wallpaper Engine:** $1.99 ($300-800/mo)
- **Steam:** $4.99 wallpaper, $9.99 native ($1,000-3,000/mo)
- **Lifetime licenses:** $49-$149 ($500/mo)

### 2. Subscriptions (~30% of revenue)
- **Patreon:** $3/$8/$15 tiers ($500-1,500/mo)
- **GitHub Sponsors:** $5/$10/$25 tiers ($300-800/mo)
- **Ko-fi Membership:** $5/$10 tiers ($100-300/mo)

### 3. Premium Content (~15% of revenue)
- **Biome DLC packs:** $2.99-$9.99 ($300-500/mo)
- **Sound packs:** $4.99 ($100-200/mo)
- **Theme packs:** $4.99 ($100-200/mo)
- **Pro features license:** $19.99/year ($300-500/mo)

### 4. Sponsorships (~10% of revenue)
- **Open Collective:** $500-2,000/mo
- **Individual sponsors:** $100-500/mo
- **Company sponsors:** $500-5,000/mo (rare, large)

### 5. Services & Custom Work (~5% of revenue)
- **Custom biome commissions:** $200-500 each
- **Consulting (game/sim dev):** $100/hr
- **Workshops/talks:** $500-2,000 each

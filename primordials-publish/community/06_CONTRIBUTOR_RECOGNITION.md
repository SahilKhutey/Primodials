# 🏆 PRIMODIALS — Contributor Recognition Framework

---

## 🎖️ HOW CONTRIBUTORS ARE CELEBRATED

1. **GitHub README & Citation Credits:**  
   Every merged PR author is automatically credited in `README.md` and included in `CITATION.cff`.

2. **Dedicated Discord Role & Channel Access:**  
   Contributors receive color-coded badges (`🌿 Biome Contributor`, `💻 Code Contributor`, `🐛 Bug Hunter`) and access to early development discussion channels.

3. **Monthly Ecosystem Spotlight in `#announcements`:**  
   On the 1st of every month, we showcase:
   - 🌿 **Biome of the Month:** Featured user-submitted JSON configuration.
   - 💻 **PR of the Month:** Highest-impact engine enhancement or optimization.
   - 🆘 **Help Champion:** Most supportive community member answering setup questions.

4. **Release Notes Changelog Attribution:**  
   Every GitHub release highlights community authors with direct links to their contributions.

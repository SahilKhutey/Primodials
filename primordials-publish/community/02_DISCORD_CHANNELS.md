# 🎮 PRIMODIALS — Channel-by-Channel Configuration & Topics

---

## 📋 DETAILED CHANNEL CONFIGURATION

### 1. Information Channels
* **`#welcome`**  
  *Topic:* Start here 👋 Welcome to Primordials! Read #rules and check #announcements.  
  *Slowmode:* 10s. Read-only for general members; bot welcome target.
* **`#rules`**  
  *Topic:* Community Code of Conduct and guidelines.  
  *Permissions:* Read-only. Pinned summary of `CODE_OF_CONDUCT.md`.
* **`#announcements`**  
  *Topic:* Official release news, blog posts, and milestone celebrations.  
  *Permissions:* Maintainers & Bots only.
* **`#changelog`**  
  *Topic:* Real-time automated GitHub Release notes and binary hashes.

### 2. Community Channels
* **`#general`**  
  *Topic:* General chat about Primordials and desktop simulation.  
  *Slowmode:* None.
* **`#introductions`**  
  *Topic:* Say hello, share where you're from, and post your desktop specs!  
  *Slowmode:* 30s.
* **`#show-and-tell`**  
  *Topic:* Share your custom biomes, fork experiments, and desktop recordings.
* **`#screenshots`**  
  *Topic:* High-resolution desktop wallpapers in the wild.

### 3. Support Channels
* **`#help`**  
  *Topic:* Installation, Wallpaper Engine setup, and multi-monitor troubleshooting.  
  *Slowmode:* 5s.
* **`#bug-reports`**  
  *Topic:* File defect reports here or directly on GitHub Issues.  
  *Slowmode:* 10s.

### 4. Biome & Development Forum Channels
* **`#biome-workshop` (Forum Mode):**  
  *Topic:* Collaborative biome design, JSON balance testing, and color palette experiments.  
  *Tags:* `[In Progress]`, `[Review]`, `[Shipped]`, `[Idea]`.
* **`#engine-discussion`**  
  *Topic:* C++23, custom ECS architecture, spatial hashing, and SDL3 hardware backends.

# 💬 PRIMODIALS — GitHub Discussions Architecture

---

## 📂 CATEGORY MAPPING

1. **📣 Announcements:** Official release notes and architectural roadmap updates (Maintainers only).
2. **🙏 Q&A:** Troubleshooting, build help, and parameter explanations (Question format with marked Accepted Answers).
3. **💡 Ideas:** Biome proposals, graphics shaders, and feature requests.
4. **🌿 Show & Tell:** Community biomes, multi-monitor setups, and fork demonstrations.
5. **💻 Development:** C++23 engine internals, ECS benchmarks, and memory optimizations.

---

## 📌 PINNED WELCOME DISCUSSION

```markdown
👋 Welcome to Primordials GitHub Discussions!

This is our long-form space for architectural discourse, biome authoring, and mathematical modeling ideas.

### Guidelines:
- **Found a reproducible bug?** Please file it under [Issues](https://github.com/SahilKhutey/Primodials/issues) with logs and system info.
- **Designing a custom biome?** Check out [docs/BIOME_SCHEMA.md](https://github.com/SahilKhutey/Primodials/blob/main/docs/BIOME_SCHEMA.md) and share your draft in *Show & Tell*!
- **Have an idea or question?** Post in *Ideas* or *Q&A*.

Thank you for helping us grow a living ecosystem together! 🧬
```

# 🛡️ PRIMODIALS — Community Moderation Playbook

---

## 🎯 MODERATION WORKFLOWS & PROTOCOLS

### 1. Spam & Automated Invasions
- **Action:** Delete offending messages immediately using `/mod purge <count>` or context menu.
- **Enforcement:** Issue a permanent ban if confirmed bot account; enable temporary verification-level raise during raid events.

### 2. Disagreements & Heated Debates
- **De-escalation:** Post a neutral mod notice in channel:  
  > *"Friendly reminder to keep discussion focused on technical trade-offs and code. Please de-escalate or take side debates to DMs."*
- **Timeout:** Apply 1-hour timeout if insults continue.

### 3. Misplaced Content / Wrong Channels
- **Guidance:** React with ➡️ and kindly redirect the author (e.g. *"Heads up: please post bug logs in #bug-reports or open a GitHub Issue"*).

---

## 📝 AUDIT LOGGING REQUIREMENTS

All moderator commands are automatically logged in `#mod-log` with timestamp, moderator username, target user, and explicit rationale.

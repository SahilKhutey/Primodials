# Changelog

All notable changes to Polygonal Primordials.

---

## [2.0.0] - 2026-08-06

### 🎉 First Public Release

#### Added
- Custom archetype-based Entity Component System (`ECS2`).
- Spatial hash broadphase for O(1) neighbor queries.
- OpenGL 4.6 instanced renderer.
- 8 heritable traits per creature (speed, size, vision, aggression, defense, metabolism, reproduction, lifespan).
- 6 atmospheric themes (`deep-sea`, `coral-reef`, `aurora`, `microorganisms`, `forest-floor`, `deep-sea-bioluminescence`).
- Live wallpaper mode for desktop background.
- System tray integration and power manager.
- 11 localized languages (EN, ES, JA, FR, DE, ZH-CN, ZH-TW, PT-BR, RU, KO, IT).
- Steam Workshop creator tools and publishing integration.

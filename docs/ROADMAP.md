# Project Roadmap

Future feature plans for Polygonal Primordials.

---

## 🎯 Near-Term (v2.1)
- Vulkan 1.3 renderer backend refinement.
- Enhanced creature mutation species tree visualization.
- Additional particle presets (storm, solar flare).

## 🚀 Long-Term (v3.0)
- Multi-node distributed simulation support.
- Neural network brain traits for creature decision making.
- Extended modding API with custom shader passes.

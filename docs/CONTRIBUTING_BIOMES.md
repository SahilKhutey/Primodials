# 🌿 How to Create & Contribute a Custom Biome

Creating a new biome in Primordials is completely accessible and requires no compiled C++ code.

---

## 1. Quick Steps

1. **Design your visual theme:** Select an inner and outer background gradient color and an array of creature hue/saturation/lightness values (`[H, S, L]`).
2. **Balance your ecology:** Choose starting counts for primary grazers and apex predators, alongside food spawning velocity.
3. **Test locally:**
   - In the web app, use the **JSON Config Import** modal.
   - Observe the ecosystem over 2–3 minutes to ensure populations do not go immediately extinct.
4. **Submit to the Community:**
   - Open a [Biome Idea Proposal](https://github.com/SahilKhutey/Primodials/issues/new?template=biome_idea.md) on GitHub with your JSON configuration!

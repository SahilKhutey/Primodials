# Steam Workshop Guide

Publishing and managing community themes via Steam Workshop.

---

## 🛠️ In-Game Workshop Tools

Polygonal Primordials includes built-in Workshop authoring tools:
1. Open **Settings → Steam Workshop → Creator Panel**.
2. Select your theme folder in `Content/Themes/`.
3. Click **Validate Theme**.
4. Click **Publish to Steam Workshop**.

---

## 🔍 Validation Rules

- `theme.json` must be valid JSON with `id`, `displayName`, and `speciesPalette`.
- Folder size must be under 50 MB.
- Must include a `preview.png` image.

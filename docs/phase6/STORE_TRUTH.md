# Store Truth Gate

Publish only what the current build can demonstrate.

## Allowed
- features verified in the build;
- measured performance with hardware/configuration;
- clearly labelled roadmap items.

## Forbidden
- concept art presented as gameplay;
- unverified FPS claims;
- unverified entity-count claims;
- multiplayer claims without the shipped feature;
- platform compatibility that has not been tested.

## Evidence chain

```text
source
→ build
→ clean-machine test
→ screenshot/video
→ store claim
```

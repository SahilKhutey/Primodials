# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.x.x   | :white_check_mark: |
| 1.x.x   | :x:                |

## Reporting a Vulnerability

The Primordials team takes security seriously. If you believe you have found a security vulnerability in either the native C++ engine, desktop installers, or the web wallpaper application, please report it responsibly.

### How to report:
1. **Email:** Send details to `security@gensoulslab.dev` or `sahilkhutey@gmail.com`.
2. **Details to include:**
   - Detailed description of the vulnerability.
   - Steps or proof-of-concept to reproduce.
   - Impact assessment (e.g., local privilege, denial of service, memory corruption).
   - Affected platform/OS.

Please **do not** report security vulnerabilities via public GitHub issues.

We will acknowledge receipt within 48 hours and work with you on a fix and coordinated disclosure.

# Contributing to Polygonal Primordials

Thank you for your interest in contributing!

---

## 🚀 How to Contribute

1. **Fork the repository**: `https://github.com/SahilKhutey/Primodials`
2. **Create a branch**: `git checkout -b feature/my-feature`
3. **Make changes & test**: `cmake --build build && ctest --test-dir build`
4. **Submit a Pull Request**: Submit PR on GitHub.

---

## 📋 Code Standards

- Follow modern C++23 standards.
- Use `std::make_unique` / `std::make_shared` (no raw `new`/`delete`).
- Keep code formatted cleanly.

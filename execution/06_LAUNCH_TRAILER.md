## 2. CRITICAL RULES

✅ **DO:**
- Capture from the actual running app
- Use real biome simulations
- Show actual UI interactions
- Include real FPS counters (if impressive)
- Use only CC0 or original audio

❌ **DO NOT:**
- Use concept art
- Show features not in v1
- Add fake overlays / effects not in product
- Use copyrighted music
- Show screenshots from other games / projects
- Claim features that don't exist

## 3. CAPTURE METHOD

```bash
# 1. Launch app with each biome
# 2. Use OBS to record full screen at 1080p 30fps
# 3. Run simulation for 10 minutes per biome
# 4. Cut the most beautiful moments

```

**Tools needed:**
- OBS Studio (free)
- DaVinci Resolve (free) — for editing
- TinyPNG / HandBrake — for compression

# Polygonal Primordials

## A Living Ecosystem Simulation

Polygonal Primordials is a data-oriented ecosystem simulation built from scratch in C++23 with a custom game engine. Watch polygonal creatures with heritable traits evolve, hunt, and reproduce in real-time.

---

## ✨ Features

- **Real Genetic Evolution** — 8 heritable traits per creature (speed, size, vision, aggression, defense, metabolism, reproduction, lifespan)
- **High Performance** — Custom ECS handling 250,000+ entities at 60 FPS
- **Emergent Behavior** — Predator-prey dynamics, speciation, extinction events, boom-bust cycles
- **Full Parameter Control** — Adjust mutation rate, population density, food spawn, predation
- **Live Visualization** — Heatmaps, population graphs, entity inspector
- **Open Source Engine** — MIT licensed, learn from the architecture
- **Cross-Platform** — Windows, Linux, macOS

---

## 🎮 What You Can Do

- Start with 10,000 creatures and watch them evolve over hours
- Tweak parameters and observe emergent consequences
- Save snapshots of interesting evolutionary moments
- View detailed population graphs and species trees
- Inspect individual creature genomes

---

## 🛠️ Technical Highlights

Built from scratch with:
- Custom archetype-based Entity-Component System (`ECS2`)
- Spatial hash for O(1) neighbor queries
- OpenGL 4.6 instanced rendering
- Custom memory allocators (pool, arena)
- Deterministic simulation with rollback support

## 🔧 Controls

- **WASD / Arrow Keys**: Pan camera
- **Mouse Wheel**: Zoom in/out
- **Space**: Pause/Resume simulation
- **Tab**: Toggle control panels
- **ESC**: Open menu
- **Left Click**: Select entity
- **Right Click + Drag**: Box select
- **F5**: Save game
- **F9**: Load game

# Polygonal Primordials — Discord Server Setup Guide

Server Name: Polygonal Primordials Official Community

## Channels Structure

### 📋 INFORMATION
- **#welcome** — Auto-greet new members and link to itch.io + GitHub
- **#announcements** — Major updates, patches, and dev logs
- **#rules** — Community guidelines (Be respectful, keep discussions relevant)

### 💬 COMMUNITY
- **#general** — General ecosystem simulation & gaming chat
- **#showcase** — Share your simulation screenshots, species trees, & GIFs
- **#help** — Troubleshooting and technical support

### 🛠️ DEVELOPMENT
- **#feedback** — Bug reports, feature suggestions
- **#modding** — Custom themes, JSON editing, & Workshop creations
- **#devlog** — Behind-the-scenes engineering snippets & benchmarks

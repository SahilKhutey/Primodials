# 🎉 Polygonal Primordials v2.0.0 — First Public Release

Polygonal Primordials is a data-oriented ecosystem simulation in C++23 where you watch polygonal creatures with heritable traits evolve in real-time.

## ✨ Features
- **Real-time Genetic Algorithms**: 8 heritable traits (speed, size, vision, aggression, defense, metabolism, reproduction, lifespan).
- **High Performance ECS**: Custom archetype-based `ECS2` handling 250,000+ entities @ 60 FPS.
- **Atmospheric Wallpaper Mode**: Run as a dynamic live desktop wallpaper with 6 themes (`deep-sea`, `coral-reef`, `aurora`, `microorganisms`, `forest-floor`, `deep-sea-bioluminescence`).
- **Interactive Game View**: Full inspect mode, population graphs, heatmaps, and ecosystem event diary.
- **Multi-Language Support**: 11 localized languages (en, es, ja, fr, de, zh-CN, zh-TW, pt-BR, ru, ko, it).
- **Open Source Engine**: MIT licensed.
